# 多无人机协同探索仿真实验总体报告

## 一、项目概述

### 1.1 系统简介

本项目为 **2D 多无人机协同探索仿真系统**，对应毕设论文第 3.6 节。系统实现了多 UAV 在未知环境中的自主探索，核心技术栈包括：

| 模块 | 实现方法 |
|------|---------|
| 环境感知 | 2D 占据栅格地图（100×100m, 0.5m 分辨率, 200×200 格） |
| 传感器模型 | 扇形视场（FOV=90°, Range=15m），60 条射线光线投射更新栅格 |
| 前沿检测 | BFS 聚类：找到已知空闲区域与未知区域的边界簇 |
| 区域分配 | Voronoi 分区：按最近距离将前沿分配给各 UAV |
| 前沿评分 | Utility = 前沿面积 / 距离 - 他机目标惩罚 |
| 路径规划 | A* 搜索 + 障碍物二值膨胀（scipy binary_dilation） |
| 防撞机制 | 分布式 ID 优先级：低 ID 优先，高 ID 让路 |
| 运动控制 | 航点跟踪：输出 (desired_pos, desired_vel) |

### 1.3 核心改造

为支持 6 个实验，对 3 个核心文件做了**向后兼容**的参数化改造：

1. **`run_exploration.py`**：`ExplorationSystem.__init__` 接受可选 `config: RunConfig`，为 None 时退化到全局常量。新增策略分发、深度模式分发、目标检测钩子、逐步指标采集。
2. **`simulation/sim_env.py`**：构造函数新增 `max_speed` 参数。
3. **`coordination/deconfliction.py`**：构造函数新增 `safe_radius` 参数。

新增模块：
- **`experiments/run_config.py`**：`RunConfig` 数据类 + `run_parametric()` 参数化运行器 + CSV/JSON 输出
- **`experiments/strategies.py`**：贪心/随机前沿选择函数
- **`experiments/depth_modes.py`**：4 种深度模式处理器 + 建图质量计算
- **`simulation/targets.py`**：目标放置、遮挡计算、4 种检测模型、多帧确认、协同响应

Exp 4B 新增模块（独立管线，不修改上述已有文件）：
- **`simulation/target_motion.py`**：CV 目标运动模型（static / linear / random_turn）
- **`simulation/occlusion_schedule.py`**：遮挡时间表（4 种模式, 可编程时段）
- **`tracking/`**：跟踪核心包（CM-KF、视觉观测、重关联、多机融合、围捕槽位）
- **`coordination/target_broadcast.py`**：目标状态广播（通信范围 + 延迟 + 丢包）
- **`coordination/target_tracking_fsm.py`**：10 状态跟踪 FSM

### 3.2 实验2：协同探索策略对比

**脚本**: `experiments/exp2_strategy_comparison.py`
**输出目录**: `output/exp2_strategy/`

#### 实验设计（6 种方法消融对比）

| 方法 | 前沿策略 | Voronoi | 防撞 | 障碍膨胀 | 说明 |
|------|---------|---------|------|---------|------|
| **Ours** | Utility 评分 | Yes | Yes | Yes | 完整系统 |
| Greedy-Frontier | 最近优先 | No | Yes | Yes | 选最近前沿 |
| Random-Frontier | 随机选择 | No | Yes | Yes | 随机选前沿 |
| w/o Voronoi | Utility 评分 | **No** | Yes | Yes | 消融 Voronoi |
| w/o Deconflict | Utility 评分 | Yes | **No** | Yes | 消融防撞 |
| w/o Inflation | Utility 评分 | Yes | Yes | **No** | 消融障碍膨胀 |

#### 生成图表（3 张）

| `fig_bar_charts.png` | 8 个指标柱状图 |
| `fig_metrics_table.png` | 指标汇总表 |

#### 核心结果

| Method | Steps | Success(%) | Coverage(%) | Path(m) | Obs Safe(%) |
|--------|-------|------------|-------------|---------|-------------|
| **Ours** | 432 | 80 | 84.6 | 457 | 63.5 |
| Greedy-Frontier | 384 | **100** | **90.1** | 532 | 69.5 |
| Random-Frontier | 800 | 0 | 55.2 | 1156 | 86.3 |
| w/o Voronoi | 392 | 90 | 88.0 | 485 | 65.6 |
| w/o Deconflict | 432 | 80 | 84.6 | 457 | 63.5 |
| w/o Inflation | 800 | **0** | **38.0** | 175 | **12.4** |

#### 关键结论

1. **障碍膨胀是最关键模块**：w/o Inflation 成功率 0%，安全率 12.4%
2. **随机前沿完全不可行**：成功率 0%，路径是 Ours 的 2.5 倍
3. **Greedy 意外良好**：100% 成功率，但路径较长（532m vs 457m）
4. **Voronoi 影响有限**：Utility 评分中的惩罚项部分替代了分区功能
5. **防撞模块无负面影响**：与 Ours 完全一致（本场景机间距充足）

| `fig_metrics_table.png` | 指标汇总表 |

#### 核心结果

| Depth Mode | Map IoU | Occ Prec | Occ Rec | Free Rec | Coverage(%) | Plan Succ(%) | Replan |
|------------|---------|----------|---------|----------|-------------|-------------|--------|
| GT-Depth | **1.000** | **1.000** | **1.000** | **1.000** | **90.1** | **100.0** | 36 |
| Ray-cast | 0.987 | 0.700 | 0.644 | 0.994 | 84.6 | 93.7 | 150 |

2. 建图质量是覆盖率的瓶颈：GT-Depth 90.1% vs Noisy-Depth 26.1%
3. 虚假障碍导致路径阻断：Noisy-Depth 重规划 776 次（GT-Depth 仅 36 次）
4. Ray-cast 是可靠基线：IoU=0.987，接近完美

### 3.4b 实验4B：遮挡目标连续跟踪与多机联合围捕

**脚本**: `experiments/exp4b_tracking_fusion.py`
**输出目录**: `output/exp4b_tracking/`

实验 4B 是实验 4 的扩展，在静态目标检测与协同响应的基础上，新增动态目标连续跟踪、多机状态融合和协同围捕三项能力。自包含仿真管线，不依赖 ExplorationSystem。

#### 三个子实验

| 子实验 | 内容 | 运行次数 | 关键变量 |
|--------|------|---------|---------|
| **4B-1** | 单机遮挡目标连续跟踪 | 720 | 3 运动 × 4 遮挡 × 4 检测器 × 3 方法 × 5 seeds |
| **4B-2** | 多机联合状态融合 | 60 | 3 遮挡 × 4 融合方法 × 5 seeds |
| **4B-3** | 协同围捕 | 15 | 3 运动 × 5 seeds |

#### 核心技术

| 技术 | 方法 |
|------|------|
| 目标运动 | CV 模型，3 模式（static / linear / random_turn） |
| 遮挡调度 | 时变遮挡（无 / 局部 / 间歇 / 全遮挡区间） |
| 跟踪 | CM-KF: $R = \lambda_c R_{det} + \lambda_o R_{occ} + \lambda_d R_{depth}$ |
| 重关联 | Mahalanobis 距离门控（$\chi^2$ 阈值 9.21） |
| 融合 | 信息滤波 / 协方差交叉 / 简单平均 / 单最优 |
| 围捕 | 自适应半径 $r_{enc} = r_{min} + k_p\sqrt{\lambda_{max}}$，等角分布槽位 |
| 状态机 | 10 状态 FSM（SEARCH → ... → ENCIRCLE → FINISH） |

**4B-1 单机跟踪**

## 六、系统性能总结

### 6.1 核心指标

| 指标 | 标准配置结果（n=3, v=3.0） |
|------|--------------------------|
| 覆盖率 | 84.6% ± 11.4%（10 种子均值） |
| 成功率 | 80%（8/10 达到 90%） |
| 碰撞数 | **0**（所有实验零碰撞） |
| 机间安全率 | **100%**（所有配置） |
| 完成步数 | 432 ± 185 步（成功场景约 340 步） |
| 路径长度 | 457m（三机总和） |
| 负载均衡 CV | 0.062 |

### 6.2 关键发现排序

1. **障碍膨胀是安全性的基石**（Exp 2：w/o Inflation 安全率 12.4%）
2. **深度精度决定建图和规划质量**（Exp 3：IoU 从 1.0 降至 0.71 时覆盖率降 3.5 倍）
3. **多机协同显著提升效率**（Exp 1：n=1→3 覆盖率从 43% 升至 89%）
4. **YOLOv5-FFM 在遮挡下优于 YOLOv5s**（Exp 4：FFM 可在中/重度遮挡下确认）
5. **CM-KF 实现遮挡下 100% 跟踪连续性**（Exp 4B-1：KF 通过预测维持遮挡期间跟踪）
6. **信息滤波融合最优**（Exp 4B-2：RMSE=0.131m，协方差迹 0.188）
7. **围捕编队快速收敛**（Exp 4B-3：静态目标 19 步形成编队，相位均匀度 0.004）
8. **系统零碰撞保证**（Exp 5/6：所有运行零碰撞）
9. **Greedy 策略意外有效**（Exp 2：100% 成功率，但路径较长）

## 七、如何运行

# 运行全部 6 个实验（约 30 分钟，不含 4B）
python run_all_experiments.py

python sim_demo.py
