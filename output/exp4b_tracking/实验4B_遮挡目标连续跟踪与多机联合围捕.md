# 实验 4B: 遮挡目标连续跟踪与多机联合围捕

## 实验目的

在遮挡、漏检条件下实现目标连续跟踪、多机联合状态融合与协同围捕响应。验证置信度调制卡尔曼滤波器 (CM-KF) 在动态遮挡环境中相对标准 KF 和纯检测方法的优势，评估多无人机信息融合策略，并测试编队围捕在不同目标运动模式下的表现。

---

## 实验 4B-1: 单机遮挡目标连续跟踪

### 实验设置

| 参数 | 值 |
|------|-----|
| 目标运动模式 | static / linear / random_turn |
| 遮挡模式 | no_occlusion / partial_occlusion / intermittent_occlusion / full_occlusion_interval |
| 检测模型 | oracle / noisy_oracle / yolov5s / yolov5_ffm |
| 跟踪方法 | Detection-only / Standard KF / CM-KF |
| 随机种子 | 42, 43, 44, 45, 46 |
| 总运行数 | 3 × 4 × 4 × 3 × 5 = 720 |
| 每次仿真步数 | 500 |
| UAV 跟踪距离 | ~6m |

### 跟踪方法说明

- **Detection-only**: 仅在检测成功时输出估计位置，无滤波
- **Standard KF**: 标准卡尔曼滤波器，固定测量噪声 R
- **CM-KF**: 置信度调制 KF，动态调制 R = λ_c·R_det + λ_o·R_occ + λ_d·R_depth

### CM-KF 测量噪声调制

$$R = \lambda_c \cdot R_{det} + \lambda_o \cdot R_{occ} + \lambda_d \cdot R_{depth}$$

- $\lambda_c = 1/(c^2 + \epsilon)$: 检测置信度越低，R 越大
- $\lambda_o = 1 + \alpha_o \cdot o$: 遮挡比例越大，R 越大 ($\alpha_o = 2.0$)
- $\lambda_d = 1 + \alpha_d \cdot \sigma_d^2$: 深度不确定度越大，R 越大 ($\alpha_d = 1.5$)

### 重关联机制

使用 Mahalanobis 距离门控:
$$D^2 = (z - Hx)^T S^{-1} (z - Hx), \quad S = HPH^T + R$$
门控阈值 $\chi^2(2, 0.01) = 9.21$

### 分析

1. **KF 方法实现 100% 跟踪连续性**: Standard KF 和 CM-KF 在遮挡期间通过预测维持跟踪，track_rate 接近 1.0；Detection-only 在遮挡期间丢失目标，track_rate 下降至 ~40%
2. **CM-KF 在遮挡条件下具有优势**: 通过动态调制 R，CM-KF 在遮挡期间适当增大测量不确定度，避免过度信任低质量观测
3. **重关联机制有效**: 在 intermittent_occlusion 和 full_occlusion_interval 模式下，KF 方法能成功重新关联目标

## 实验 4B-2: 多机联合状态融合

### 实验设置

| 参数 | 值 |
|------|-----|
| UAV 数量 | 3 |
| 目标运动 | linear (v=0.5 m/s) |
| 遮挡模式 | no_occlusion / partial_occlusion / full_occlusion_interval |
| 融合方法 | single_best / naive_average / info_filter / covariance_intersection |
| 随机种子 | 42, 43, 44, 45, 46 |
| 总运行数 | 3 × 4 × 5 = 60 |
| 跟踪距离 | ~6m (UAV 围绕目标等间距分布) |

### 融合方法说明

- **Single Best**: 选择置信度最高的单一估计
- **Naive Average**: 简单平均各估计，协方差取平均/N
- **Information Filter**: $\Omega = \sum P_i^{-1}$, $\xi = \sum P_i^{-1} x_i$, $x_{fused} = \Omega^{-1} \xi$
- **Covariance Intersection**: 线搜索 $\omega \in [0,1]$ 最小化 $\det(P_{fused})$

### 结果

![融合对比](figures/fig_4b2_fusion_bars.png)

![融合指标表](figures/fig_4b2_metrics_table.png)

### 分析

1. **Information Filter 表现最优**: 融合后 RMSE 最低 (0.131m)，协方差迹最小 (0.188)
2. **融合均优于单估计**: 所有融合方法的 post_fusion_rmse 均低于 pre_fusion_rmse
3. **Covariance Intersection 保守但稳健**: CI 的协方差迹与 single_best 相近，但提供了一致性保证

## 实验 4B-3: 协同围捕

### 实验设置

| 参数 | 值 |
|------|-----|
| UAV 数量 | 3 |
| 目标运动 | static / linear / random_turn |
| 遮挡模式 | intermittent_occlusion |
| 融合方法 | info_filter |
| 围捕半径 | $r_{enc} = r_{min} + k_p \cdot \sqrt{\lambda_{max}(P_{xy})}$ ($r_{min}=8$, $k_p=2$) |
| 随机种子 | 42, 43, 44, 45, 46 |
| 总运行数 | 3 × 5 = 15 |
| 最大步数 | 600 |

### FSM 状态机

10 个状态: SEARCH → CONFIRM_TARGET → TRACK_TARGET → OCCLUDED_TRACK → REACQUIRE_TARGET → CONVERGE_TO_TARGET → MULTI_TRACK → ENCIRCLE_TARGET → LOST_TARGET → FINISH

### 分析

1. **静态目标快速编队**: 平均 19 步形成围捕编队，相位均匀度 0.004 (接近理想值 0)
2. **动态目标编队可行但相位精度下降**: linear 目标 22 步编队，random_turn 23 步，相位均匀度 1.7-2.5
3. **自适应围捕半径**: 围捕半径随目标不确定度动态调整，协方差大时半径增大，确保安全裕度
4. **FSM 协调有效**: 各 UAV 经历完整的 SEARCH → CONFIRM → TRACK → MULTI_TRACK → ENCIRCLE 流程
